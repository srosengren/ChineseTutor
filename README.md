# ChineseTutor

A reading aid for learners of Chinese. Paste text in Simplified Chinese and read it with
word boundaries, pinyin, and one-tap dictionary entries.

**Status:** design phase, no app yet.

- [Architecture overview](docs/architecture.md)
- [Architecture Decision Records](docs/adr/README.md)

The web app will be published at https://srosengren.github.io/ChineseTutor/.
